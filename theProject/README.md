# منهج البرمجة والذكاء الاصطناعي ثانيه بكالوريا — الصف الثاني الثانوي (المنهج الكامل)
## إعداد وتدريس: المهندس عمر محمود — 01012306019
### الوحدة الأولى: تكنولوجيا المعلومات والمجتمع (كتاب الوزارة ص 4 إلى ص 30)

---
### المحتويات الشاملة والمطورة في هذا الإصدار الاحترافي:
1. تغطية شاملة وتفصيلية بنسبة 100% لكل دروس الوحدة الأولى (1-1، 1-2، 1-3، 1-4).
2. إدراج كافة العناصر الجانبية الرسمية لكتاب الوزارة لكل درس:
   - توقف وفكر (Pause & Think)
   - استقصِ كمهندس (Investigate Like an Engineer)
   - فكر كمهندس (Think Like an Engineer)
   - سؤال على نمط الامتحان (6 درجات) مع نموذج الإجابة وتوزيع الدرجات
3. التشريح الكامل للشبكات العصبية الاصطناعية (ANN) بتسمية صريحة لطبقة الإدخال والطبقات المخفية وطبقة الإخراج والأوزان.
4. بنك أسئلة شامل وحلول كتاب الوزارة الكاملة (ص 31 - 35).
5. الامتحان الشامل للوحدة الأولى (25 سؤالاً منهجياً) مع احتساب الدرجة واستخراج شهادة الإتقان.
6. نظام ثنائي اللغة (العربية / الإنجليزية) والوضع الليلي والنهاري.
7. مذكرة المراجعة السريعة الجاهزة للطباعة PDF.
